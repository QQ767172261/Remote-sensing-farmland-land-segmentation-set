## 标签
**农田地块（Farmland-Parcel）**，单类别实例分割，识别遥感影像中每一块独立耕地的边界轮廓，区分不同地块。

## 应用场景
1. 国土自然资源调查、耕地地块提取、农田边界自动测绘
2. 农业遥感，耕地面积统计、地块分割、地块权属图斑识别
3. 无人机/卫星遥感图像实例分割算法训练、U-Net、YOLO-seg、MaskRCNN模型实验
4. 毕业设计、科研论文、土地利用变化监测、智慧农业地块管理
